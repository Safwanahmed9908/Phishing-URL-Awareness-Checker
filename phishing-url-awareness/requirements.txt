# Phishing URL Awareness Checker - Requirements

# Standard Library Modules Used:

# - ipaddress    (for validating whether a host is a raw IPv4/IPv6 address)
# - re           (for regular expression checks and string sanitization)
# - sys          (for system-level arguments and clean program exit)
