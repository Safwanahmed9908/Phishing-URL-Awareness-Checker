# Phishing Detector – Phishing URL Awareness

## About the Project

Phishing Detector is a web-based application designed to help users identify potentially malicious or phishing URLs. It helps users understand URL security and avoid suspicious websites.

## Features

- Check suspicious URLs.
- Identify potential phishing websites.
- Simple and user-friendly interface.
- Helps improve cybersecurity awareness.
- Provides URL analysis results.

## Technologies Used

- Python
- Flask
- HTML
- CSS
- JavaScript

## Installation and Setup

1. Clone the repository:

```bash
git clone https://github.com/Safwanahmed9908/Phishing-detector.git
```

2. Open the project folder:

```bash
cd Phishing-detector
```

3. Install dependencies:

```bash
pip install -r phishing-url-awareness/requirements.txt
```

4. Run the application:

```bash
python app.py
```

5. Open your browser and visit:

```text
http://127.0.0.1:5000
```

## Purpose

The main objective of this project is to spread phishing awareness and help users recognize potentially unsafe URLs.

## Disclaimer

This project is developed for educational purposes and cybersecurity awareness. Detection results are not guaranteed to identify every phishing website.
